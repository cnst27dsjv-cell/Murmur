# Murmur Pet Lottie Assets

This folder contains the first lightweight Lottie pet animation assets.

- `idle.json`: a quiet 512 x 512 idle breathing loop.
- `hover.json`: a curious hover lift with small sparkles.
- `tap.json`: a quick click bounce.
- `cheer.json`: a happy to-do completed reaction with a heart.
- `sleep.json`: a sleepy loop with drifting Zzz.
- `talk.json`: a future AI/talking loop with animated dots.
- `images/cat_full.png`: the transparent cat image used by `idle.json`.

Image helpers:

- `images/cat_sit.png`: used by `cheer.json`.
- `images/cat_sleep.png`: used by `sleep.json`.
- `images/heart.png`: used by `cheer.json`.
- `images/sparkle.png`: used by `hover.json` and `cheer.json`.
- `images/zzz.png`: used by `sleep.json`.
- `images/talk_dot.png`: used by `talk.json`.

Keep each animation short, transparent, and centered on a 512 x 512 canvas.

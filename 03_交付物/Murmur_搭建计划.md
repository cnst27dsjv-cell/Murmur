# Murmur V1 搭建计划

## 当前技术选择

先使用 macOS 原生 Swift/AppKit 搭建一个可运行的桌面 app 骨架。当前机器没有完整 Xcode 工具链，因此第一阶段采用 Swift Package 形式运行；后续准备上架时，再迁移到标准 Xcode app 工程、补充签名、图标、权限说明和打包流程。

## 阶段 1：项目基础结构

- 创建 `Package.swift`。
- 创建 `Sources/MurmurApp/` 源码目录。
- 创建 app 入口、状态栏菜单、主桌面组件窗口。
- 创建 `README.md`，说明如何运行。

## 阶段 2：V1 核心桌面组件

- 创建透明无边框窗口。
- 渲染毛玻璃组件主体。
- 实现默认模糊封面。
- 实现点击组件主体切换模糊/清晰。
- 桌宠独立于封面层，始终保持清晰。
- 预留封面切换动画结构，V1 默认淡入淡出。

## 阶段 3：内容与本地存储

- 定义组件状态、本地内容、任务、封面、桌宠配置的数据模型。
- 使用本机 Application Support 目录保存 JSON。
- 提供默认数据。
- 支持重启后恢复内容、模糊状态和窗口位置。

## 阶段 4：轻编辑与设置面板

- 清晰状态下展示主文案、私密碎碎念和极简任务列表。
- 支持任务勾选。
- 设置面板支持编辑主文案、私密碎碎念、封面文案。
- 设置面板支持选择封面图片和桌宠图片的本地路径。
- 后续再增强组件内新增/编辑任务的体验。

## 阶段 5：基础验证

- 使用 SwiftPM 构建验证。
- 本机运行检查窗口能打开。
- 检查模糊切换、桌宠清晰、本地保存、重启恢复。

## 暂不做

- 多组件。
- 云同步。
- 动态桌宠。
- 复杂任务提醒。
- App Store 打包。
- 模板市场和付费功能。

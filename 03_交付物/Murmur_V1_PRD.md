# Murmur V1 PRD

## 1. 产品定位

Murmur V1 是一个 macOS 桌面组件 app。它把心情、轻量待办和自我提醒放进一个高级、个性化、可保护隐私的桌面组件里。

它不是重度任务管理工具，也不是单纯桌宠。核心体验是：桌面上有一个像私人杂志页一样的透明磨砂组件。默认状态下，内部内容被个性化模糊封面保护；点击组件主体后，内部内容清晰显示；桌宠或个人卡通形象始终贴在组件边缘，并保持清晰。

核心卖点：

> 把心情、待办和自我提醒放在桌面上。

## 2. V1 产品目标

V1 要做成一个稳定、能自用、有完整体验的 macOS 桌面小工具。第一版不追求复杂功能，但视觉和核心交互要成立，并为未来上架保留空间。

成功标准不是“任务管理很强”，而是用户愿意每天把它留在桌面上。

## 3. 用户价值

- 用户可以把当天的心情、自我提醒和轻量任务放在桌面上。
- 用户可以默认隐藏私密内容，旁边有人或共享屏幕时也不容易暴露。
- 模糊封面不是普通遮罩，而是可以展示图片、表情包或一句话的个性化封面。
- 桌宠/个人形象提供陪伴感和识别度，并始终清晰可见。
- 所有内容都只保存在本机，符合私人桌面角落的定位。

## 4. V1 功能范围

### 4.1 主桌面组件 / 边缘抽屉

- V1 只做一个主组件。
- V1 采用“屏幕边缘吸附 + 桌宠展开”的交互：平时只露出桌宠，吸附在屏幕左侧或右侧；点击桌宠后展开完整组件。
- 组件需要低打扰、可恢复位置。
- 数据结构预留未来多组件扩展。

### 4.2 默认模糊封面

- 组件默认进入模糊封面状态。
- 封面隐藏内部任务、主文案和私密碎碎念。
- 封面中央支持三类内容：
  - 用户选择的图片；
  - 表情包/贴纸；
  - 座右铭或喜欢的话。
- 点击组件主体后，封面淡出，内部内容清晰。
- 再次点击组件主体后，回到模糊封面状态。
- V1 默认使用淡入淡出切换；动画结构需要预留扩展，后续可支持不同封面揭开效果。

### 4.3 桌宠/个人形象

- 桌宠始终保持清晰，不受模糊封面影响。
- 桌宠贴在组件边缘，例如上边缘、右上角、下边缘。
- V1 提供内置静态角色。
- V1 支持用户上传自己的宠物、头像、贴纸或卡通形象。
- V1 不做动态桌宠，后续版本再做动效、待机状态和互动。

### 4.4 心情与自我提醒

- 清晰状态下展示一句主文案。
- 支持一段更私密的碎碎念。
- 主文案负责桌面上的情绪表达。
- 私密碎碎念负责更个人的记录或提醒。

### 4.5 极简 to-do list

V1 的待办只做轻量能力：

- 新增任务；
- 编辑任务；
- 勾选完成；
- 删除任务。

V1 不做截止日期、提醒通知、项目分组、重复任务或复杂优先级。

### 4.6 编辑方式

- 简单内容支持在组件中快速编辑，例如勾选任务、添加任务、编辑主文案。
- 复杂配置进入设置面板，例如封面、宠物、透明度、模糊强度、素材上传等。
- 组件本体不堆太多按钮，避免破坏桌面美感。

### 4.7 设置面板

设置面板负责：

- 选择封面类型；
- 上传封面图片或表情包；
- 编辑封面文案；
- 选择内置桌宠；
- 上传自定义桌宠/个人形象；
- 调整桌宠位置；
- 调整透明度；
- 调整模糊强度；
- 管理主题色和视觉参数；
- 编辑主文案、私密碎碎念和任务内容。

### 4.8 本地存储

- 所有任务、文字、组件状态、位置和素材都只保存在本机。
- V1 不做账号、登录和云同步。
- 后续可以考虑导入/导出、iCloud 或账号同步，但 V1 不实现。

## 5. 视觉方向

V1 视觉方向是：

> 冷淡高级 + 可爱点缀

### 5.1 组件本体

- 透明磨砂毛玻璃质感；
- 细边框；
- 轻阴影；
- 适中圆角；
- 低饱和色彩；
- 不做厚重卡片。

### 5.2 色彩

底色以雾白、银灰、淡蓝灰、浅暖灰为主。可以有少量主题色，但不走高饱和路线。

### 5.3 排版

- 主文案可以更有杂志感和情绪感；
- to-do 文本要清晰实用；
- 私密碎碎念要更柔和；
- 整体保持留白，不做拥挤工具面板。

### 5.4 个性化表达

- 封面图、表情包和封面文案承担个性表达；
- 桌宠承担陪伴感和视觉识别；
- 组件底子保持高级克制，避免变成过度可爱或过度装饰。

## 6. 核心交互流程

### 6.1 首次打开

用户打开 app 后，看到一个默认透明磨砂桌面组件。组件包含默认封面、示例内容和一只内置静态桌宠。

用户可以直接使用，也可以进入设置面板自定义。

### 6.2 日常桌面状态

组件默认模糊，封面中央显示用户配置的图片、表情包或文字。桌宠始终在组件边缘保持清晰。

### 6.3 查看内容

平时 Murmur 只露出桌宠，并吸附在屏幕左侧或右侧。用户点击桌宠后，完整组件从屏幕边缘展开。

组件展开后，如果处于模糊状态，用户点击组件主体，封面淡出，内部内容变清晰。用户可以看到主文案、私密碎碎念和 to-do list。再次点击组件主体，内部内容回到模糊封面状态。

桌宠在整个过程中始终保持清晰。

用户可以拖动桌宠或组件，松手后组件自动吸附到更近的屏幕边缘。

V1 默认使用淡入淡出动画，后续可扩展为更多封面切换效果，例如轻推开、玻璃雾气散开、翻页、拉帘或聚焦显影。

### 6.4 快速编辑

清晰状态下，用户可以快速勾选任务、新增任务、编辑任务和编辑主文案。

### 6.5 深度配置

用户通过组件轻入口或菜单栏入口打开设置面板，进行封面、宠物、视觉和素材配置。

### 6.6 重启恢复

关闭 app、重启 app 或重启 Mac 后，组件恢复上次的位置、模糊状态、内容、任务、封面、宠物和视觉设置。

## 7. 产品结构

V1 拆成四个主要部分：

### 7.1 桌面组件窗口

负责展示主组件、模糊封面、清晰内容、桌宠位置、点击切换和轻量就地编辑。

### 7.2 设置面板

负责封面、桌宠、视觉参数、素材上传和深度内容配置。

### 7.3 本地数据与素材存储

负责保存任务、文字、组件位置、模糊状态、视觉配置、封面素材和桌宠素材。

### 7.4 样式/主题系统

负责管理透明度、模糊强度、圆角、边框、阴影、主题色和未来模板扩展。

## 8. 数据要求

V1 数据至少需要包含：

- 组件状态：
  - id；
  - 位置；
  - 尺寸；
  - 是否模糊；
  - 主题设置；
  - 封面设置；
  - 桌宠设置。
- 内容：
  - 主文案；
  - 私密碎碎念；
  - 任务列表。
- 任务：
  - id；
  - 文本；
  - 是否完成；
  - 创建时间；
  - 更新时间。
- 素材：
  - id；
  - 类型；
  - 本地路径；
  - 展示配置。

虽然 V1 只有一个组件，但数据设计不应写死“永远只有一个组件”。

## 9. 异常与空状态

V1 需要优雅处理：

- 上传图片格式不支持；
- 上传图片过大；
- 用户移动或删除了本地素材；
- 本地数据读取或写入失败；
- 多显示器变化导致组件位置跑到屏幕外；
- 用户删除所有任务；
- 用户清空主文案或私密碎碎念。

预期处理：

- 素材缺失时使用默认备用素材；
- 组件位置超出屏幕时自动拉回可见区域；
- 没有任务时显示轻量空状态；
- 技术错误不直接暴露在桌面组件上。

## 10. V1 不做什么

- 不做多个桌面组件。
- 不做账号、登录、云同步。
- 不做复杂任务系统。
- 不做动态桌宠。
- 不做模板市场、付费体系、社区分享。
- 不做 Windows 或跨平台。
- 不做重型富文本编辑器。

## 11. 验收标准

1. 用户能在 macOS 桌面上看到一个常驻、低打扰的透明磨砂组件。
2. 组件默认模糊，封面可显示用户配置的图片、表情包或文案。
3. 点击组件主体后，内部内容清晰；再点恢复模糊。
4. 桌宠在模糊和清晰状态下都始终清晰。
5. 用户能维护一句主文案、一段私密碎碎念和一个极简 to-do list。
6. 用户能新增、编辑、勾选完成和删除任务。
7. 用户能选择内置桌宠或上传自己的宠物/卡通形象。
8. 用户能配置封面图片、表情包或封面文案。
9. 关闭或重启后，组件内容、位置、模糊状态和素材能恢复。
10. 所有数据只保存在本机。
11. 整体视觉符合“冷淡高级 + 可爱点缀”。

## 12. 后续版本方向

- 多组件；
- 动态桌宠；
- 桌宠待机动作和互动；
- 共享屏幕/工作场景自动隐私模式；
- 更多封面揭开/隐藏动画效果；
- 导入/导出；
- iCloud 或账号同步；
- 模板包；
- 付费主题；
- App Store 上架；
- Windows 支持。
